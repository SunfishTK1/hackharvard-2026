# server/

Everything that runs the shared team server: `bootstrap.sh` (sets up a fresh machine), `deploy.sh` (ships an app folder to it), `proxy/` (Caddy, HTTPS for every app) and `docs/` (the server guide).

**The server guide is [docs/site/README.md](docs/site/README.md)**, published at https://hackharvard2026.velroi.com and at `/opt/apps/README.md` on the server. Rules for AI agents: [docs/site/AGENTS.md](docs/site/AGENTS.md).
